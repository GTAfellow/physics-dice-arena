# physics-dice-arena

Vue 3 + Vite 版物理骰子竞技场。

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 骰子塔

骰子从顶部依次投下，沿两块前后交错的斜板翻滚，再通过底部坡道进入接骰盘。塔身透明，模型与碰撞体共用尺寸；塔内不使用强推、超时瞬移或强制停止。

两种场景统一采用 1/960 秒固定物理步长，并针对 Cannon 0.6.2 修正摩擦力到每步冲量的换算，同时在各接触点之间分配摩擦预算，让骰子能自然停转。

## 盘子与速度

盘子采用黑色绒面衬底与木纹围边，围边深度为 2.6 个场景单位。围边模型和实体碰撞体共用半径、厚度和深度，盘内采用高度一致的平面支撑以避开旧版 Cannon 的薄圆柱接触抖动，不使用越界瞬移。

以 D6 边长 16 mm 为明确的尺寸假设：1 个场景单位约为 15.24 mm，盘子内径约 26 cm、深度约 4 cm，骰塔高度约 30 cm。标准重力为 9.80665 m/s²，换算为约 643.56 场景单位/s²；旧重力 14.5 场景单位/s² 在此比例下仅约 0.22 m/s²，明显偏慢。

自由落体 10 cm 的物理理论时间约为 0.143 秒。为便于看清出手与翻滚，两个场景统一以 0.5 倍速播放，屏幕上约为 0.286 秒；这是有意放慢的展示速度，不是真实时间下的自由落体速度。`PHYSICS.playbackSpeed` 控制播放倍率，重力与碰撞计算仍保留原物理配置。线性空气阻尼设为 0.01，物理时钟按前台经过时间乘以播放倍率推进，不依赖渲染帧率；每帧最多补算 96 步，未处理时间留待后续帧补算，避免长帧卡死。后台标签页暂停，恢复时不补算长时间的后台运动。木材、绒面与骰子的碰撞系数仍是近似值，并非特定实物的测量数据。

盘子投骰带有朝盘内的横向初速度、轻微向上的速度与多轴旋转，骰塔投骰带有朝首块斜板的初速度与翻滚。初速度仅在出手时设置一次，之后由重力、碰撞和摩擦自然推进，不持续施加额外推力。

标准重力参考：[NIST SP 330](https://www.nist.gov/pml/special-publication-330/sp-330-appendix-1)。

## 骰子与读数

D4 使用顶点编号，读最高顶点，三个可见面在同一顶点处的数字一致。D6/D8/D12/D20 使用正多面体，对面数字和分别为 7/9/13/21。相邻数字的排列在不同厂商间并不完全统一，本项目使用对面互补的排列，不声称复刻某一厂商的全部排布。D012 保留原设计。

D10 和百分位骰使用十个全等、平面的风筝面构成的五方偏方面体。D10 印 0-9，独立投骰时 0 读作 10，对面印字和为 9；百分十位骰印 00-90，对面印字和为 90。D100 使用十位和个位两颗骰子的实际朝向，00 + 0 为 100，其余直接相加。

D&D 的标准骰子组原本已齐全，另补充 D2、D3 和可单独投掷的 D% 十位骰。D2 使用 D6 三个面读 1、三个面读 2；D3 使用 D6 每两个面对应 1/2/3，均为等概率折算，不冒充实际两面或三面多面体。增加 Fate 的 DF 骰，正号、空白、负号各两面，对应 +1/0/-1。当前提供骰子和加总，不包含整套 RPG 规则裁决、混合骰表达式、优势/劣势或修正值系统。

几何采用理想的锐边凸多面体，未模拟某个厂商的倒角、制造公差和重量分布；几何对称不等于已经通过统计公平性认证。正多面体的内部二面角：D4 70.5288°、D6 90°、D8 109.4712°、D12 116.5651°、D20 138.1897°。D10 的高宽比例可变化，因此没有唯一的实体骰标准夹角；当前模型保持轴向对称，存在约 86.4018° 与 129.9416° 两类二面角。

规则与几何参考：[D&D Basic Rules](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/introduction#GameDice)、[Fate SRD](https://fate-srd.com/fate-core/taking-action-dice-ladder)、[MathWorld 正多面体](https://mathworld.wolfram.com/PlatonicSolid.html)、[MathWorld 偏方面体](https://mathworld.wolfram.com/Trapezohedron.html)。

## 镜头与移动端

移动端默认采用更高的俯视角，骰塔优先展示接骰盘，塔顶允许出画。镜头以二分搜索贴合可用区域，面板尺寸变化时重新取景。菜单向下收起后保留展开按钮、结果与独立投掷按钮。提示根据浏览器的粗指针能力分别显示单指/双指手势或鼠标操作；支持重置镜头、设备旋转和安全区域。

结果不等待 Cannon 休眠。所有骰子出塔/入盘、速度足够低且读数、位置与角度连续稳定 150 ms 后即可显示；仍在运动或出现姿态变化时重新确认，不强制停止骰子。如果两个面几乎同样朝上，则提示歪骰并请求重掷，不编造一个确定结果或总和。

## 结构

- `src/App.vue`: 应用状态、语言、校验和投掷流程
- `src/components/DiceControls.vue`: 控制面板组件
- `src/physics/createDiceArena.js`: Three.js + Cannon.js 物理渲染引擎
- `src/physics/diceGeometry.js`: 渲染和回归测试共用的骰子形状及尺寸
- `src/physics/towerPhysics.js`: 骰塔结构、材质、投骰入口与摩擦求解修正
- `src/physics/dishPhysics.js`: 盘子尺寸、连续围边碰撞体与投骰入口
- `src/physics/physicsSettings.js`: 实物尺寸比例、重力、物理时钟与摩擦求解器
- `src/physics/diceResults.js`: 面读数、百分骰计算与稳定判定
- `tests/tower.test.mjs`: 骰塔物理回归测试
- `tests/dish.test.mjs`: 盘子物理回归测试
- `tests/physics.test.mjs`: 下落速度及帧率一致性测试
- `tests/launch.test.mjs`: 出手初速度与旋转测试
- `tests/geometry.test.mjs`: 多面体、编号与朝向读数测试
- `tests/results.test.mjs`: 快速稳定判定测试
- `src/i18n.js`: 中英文文案和骰子选项
- `src/styles.css`: 全局样式
